# 温馨诊所管理系统

面向门诊、诊所及基层医疗机构的一体化业务管理系统，覆盖患者接诊、电子病历、处方开立、收费退费、药房发药、治疗执行、库存管理、会员管理、经营统计和票据打印等日常工作。

> 本仓库仅用于产品介绍、版本发布和安装包下载，不提供项目源代码。

## 主要功能

- **患者管理**：患者档案、就诊记录、病史资料、会员余额及消费流水。
- **诊疗业务**：电子病历、诊断、药品处方、注射处方、治疗项目和医嘱执行。
- **收费管理**：处方收费、零售收费、多种支付方式、欠费、退款及收费记录。
- **药房管理**：待发药、发药、退药、重新发药及药品数量追踪。
- **库存管理**：药品资料、供应商、采购入库、库存盘点、领用和库存流水。
- **会员服务**：会员充值、储值金与赠送金管理、会员卡支付和消费账单。
- **统计报表**：收费日报、收费明细、欠还款明细、收费项目及会员消费统计。
- **项目费用**：注射处方产生服务费用，设置服务费用价格，关联耗材。
- **打印中心**：处方、医嘱、收费票据、零售单据和发药单据等模板化打印。
- **数据维护**：本地数据存储、附件管理、手动备份与备份恢复。

## 下载与安装

安装包仅通过本仓库的 **Releases** 页面发布：

### [前往 Releases 下载最新版本](../../releases/latest)

1. 在最新版本中下载 Windows 安装程序（`.exe`）。
2. 退出正在运行的旧版本客户端。
3. 运行安装程序，并按提示完成安装或升级。
4. 首次启动或跨版本升级时，系统可能需要执行数据迁移，请勿强制关闭程序。

请只从本仓库 Releases 或[官方网站](http://www.ai-clinic.cn)下载安装包。安装前请核对版本号、文件名和发布来源，不要运行来源不明的安装文件。

## 系统要求

- 操作系统：Windows 10 / Windows 11（64 位）
- 建议使用常用纸张规格或 80mm 热敏票据打印机完成业务单据打印
- 在线检查版本和获取更新信息时需要网络连接，诊所日常业务数据保存在本机

## 升级与数据安全

- 安装新版本前，建议在系统的“数据与备份”中执行一次完整备份。
- 备份应保存到安装目录和数据目录以外的安全位置，并定期复制到其他存储介质。
- 升级期间请保持电源稳定，不要结束客户端进程或移动数据库文件。
- 更换电脑、重装系统或调整数据目录前，请先确认备份文件可以正常读取。
- Release 说明中会列出版本变化和必要的升级提示，请在升级前仔细阅读。

## 问题反馈

如遇到无法启动、数据迁移失败、打印异常或业务数据不一致，请记录以下信息后联系技术支持：

- 当前客户端版本和 Windows 版本
- 问题发生时间及具体操作步骤
- 完整的错误提示或截图
- 是否刚完成安装、升级、恢复备份或切换数据目录

请勿在公开 Issue 中上传患者资料、处方、手机号、身份证号、数据库、日志或备份文件等敏感信息。
